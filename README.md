# aegys 

This repository contains both the backend (FastAPI) and frontend (React) for the aegys warranty and bill organizer platform.

## Structure
- `backend/` — FastAPI backend, MongoDB, file storage, warranty extraction, API endpoints
- `frontend/` — React client, Tailwind CSS, Zustand, Clerk, Framer Motion

## Setup
- See `backend/README.md` for API and backend setup
- See `frontend/README.md` for client setup

## Features
- Upload and parse warranty/bill files
- Track device coverage and service records
- Alerts for expiring warranties
- User profile and statistics
- Modern, responsive UI
